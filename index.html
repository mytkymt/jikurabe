Jikurabe

書体を重ねて字形の違いを見比べる
和文フォント用 type diff ツール

読み込むと、インストール済みフォントが下の検索候補に加わります（Chrome / Edge）

      Jikurabe（字比べ）とは

      Jikurabe は、2つの日本語フォントを同じ位置に青と赤で重ねて表示し、字形の違いをひと目で見比べるための無料の Web ツールです。ゴシックと明朝、Noto Sans JP と Zen Kaku Gothic New のような似た書体同士、ウェイト違いなど、並べただけでは分かりにくい「はらい」「ふところ」「重心」「字面の大きさ」の差が、重ねることで浮かび上がります。書体選び、フォントの置き換え検討、タイポグラフィの学習に使えます。

      使い方

      1. Font A / Font B にフォント名を入力します。入力欄を押すと候補が開き、「明朝」「丸」「しっぽり」のような部分一致でも絞り込めます。候補は各フォントで「永あ」がプレビューされます。
      2. ウェイトを選びます（Google Fonts の書体は、そのフォントが持つウェイトだけが選べます）。
      3. 比較する文字を書き換えます。ひらがな・カタカナ・漢字・約物・欧文・数字のプリセットも用意しています。
      4. 必要に応じて「A のみ / B のみ」「塗り / 輪郭」「罫線を表示」を切り替えます。
      5. 「X で共有」や「この比較のリンクをコピー」で、同じ比較を URL として共有できます。

      使えるフォント

      • Google Fonts の和文書体 — 日本語サブセットを持つ 68 ファミリー。
      • PC にインストール済みのフォント — フォント名を直接入力するか、Chrome / Edge では「PC のフォント一覧を読み込む」で候補に追加できます（ヒラギノ、游ゴシック、游明朝、メイリオ、小塚、モリサワや Fontworks の製品フォントなど、インストール済みなら何でも）。
      • フォントファイル — .otf / .ttf / .woff / .woff2 を「ファイル…」から開けます。ファイルはブラウザ内だけで処理され、サーバーには送信されません。制作中のフォントや、購入したフォントの検討にも使えます。

      差分％の見方

      各文字の下に出る差分％は、2つの字形のどちらかが塗られている面積のうち、片方だけが塗られている面積の割合です（XOR ÷ OR）。0% なら完全に同じ形、100% なら重なりがまったくない形です。同じ書体のウェイト違いで 10〜20%、ゴシックと明朝の比較で 40〜60% 程度が目安になります。字面の大きさや重心のずれも差分に含まれるので、「字形が似ているのに％が高い」場合は位置やサイズの違いの可能性があります。フォールバック書体で比較してしまうことを防ぐため、フォントがその文字を持たない場合は「グリフなし」と表示しています。

      よくある質問

      無料ですか？
      無料です。登録も不要で、ブラウザだけで動きます。ソースコードは GitHub で公開しています。
      フォントファイルをアップロードして大丈夫ですか？
      ファイルは JavaScript でブラウザ内に読み込まれるだけで、サーバーには一切送信されません。ページを閉じれば消えます。
      元になったツールは？
      欧文フォント向けの Tiff（@winnie_the_mu）に着想を得て、日本語フォント向けに新しく実装したものです。
      スマートフォンでも使えますか？
      使えます。PC のフォント一覧の読み込みだけは、デスクトップの Chrome / Edge が必要です。

      オリジナルの Tiff（by @winnie_the_mu）に着想を得た、日本語フォント向けの実装です。差分％は、2つの字形のどちらかが塗られている面積のうち、片方だけが塗られている面積の割合です。
